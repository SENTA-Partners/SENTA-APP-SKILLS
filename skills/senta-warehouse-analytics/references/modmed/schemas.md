# Schema Locations: MODMED.DATA vs MODMED.ANCILLARY vs MODMED.SNAPSHOTS

The dictionary tables are physically split across two schemas, plus a point-in-time schema:

- **MODMED.DATA** — the primary schema. If a table is NOT in the Ancillary list below, query it at `Modmed.Data.<table>`.
- **MODMED.ANCILLARY** — holds the tables listed below (mostly clinical/chart detail, histories, faxes, tasks, orders/results, ophthalmic measurements, static/config tables). Query at `Modmed.Ancillary.<table>`.
- **MODMED.SNAPSHOTS** — point-in-time copies of MODMED.DATA tables with an added **`report_date`** column. Every table listed in the Snapshots section exists at `Modmed.Snapshots.<table>`. Use for "as of" analysis (e.g., AR as of month-end) and trending metrics over time. ALWAYS filter `report_date` first — these tables are very large (hundreds of millions of rows).

If a table appears in both lists below, it exists in both schemas — default to MODMED.DATA (or MODMED.ANCILLARY per the list) for current-state and MODMED.SNAPSHOTS only for point-in-time. When unsure, verify with `SHOW TABLES LIKE '<table>' IN SCHEMA Modmed.Data;`.
